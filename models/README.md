# Local Model Checkpoints Directory

This directory stores fine-tuned character-level (DictaBERT-char, TavBERT) and WordPiece (MsBERT) model checkpoints:

- `models/ft_tavbert_span_preserved_nonbib_seed42`: Fine-tuned TavBERT base checkpoint.
- `models/ft_msbert_span_refined`: Fine-tuned MsBERT checkpoint.
- `models/ft_byt5_span_preserved_nonbib_seed41`: Fine-tuned ByT5-small checkpoint.

Model weights are ignored by git (`.gitignore`).
